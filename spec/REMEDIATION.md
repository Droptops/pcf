# Ultra-review remediation

PCF 0.2 includes changes aimed at 14 findings from an earlier review. That review is not in this repository, and the items are not individually linked to tests: provider marker placement and model profiles; stable cache partitions; structured tool history; read-only TTL inspection; stable Platt fitting; held-out calibration eligibility; nullable confidence and real fallback behavior; cache-write pricing; descriptor/byte-compatibility separation; strict schemas and finite numbers; provider boundary/authority handling; RFC 8785 canonicalization; input/metrics validation; and provenance-preserving external documents. A later review found gaps in several of these areas (Platt-fit convergence, schema/runtime parity, validation with no selected samples, OpenAI history rendering); see `CHANGELOG.md`.

Intentional claim limits: closed-provider warmth is unknown before execution, synthetic validation is not a production-quality certificate, and no component claims cross-family raw KV transfer.
