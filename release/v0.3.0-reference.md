# PCF v0.3.0 Reference Milestone

Date: 2026-10-05

Status: **complete reference system**

This milestone freezes the PCF v0.3 reference implementation and its canonical live validation evidence. It is a completion marker for the reference architecture, not a claim that the preregistered production-release gate has passed.

## What is complete

- Provider-neutral PCF compilation and cache-aware placement for OpenAI and Anthropic.
- Durable/idempotent MemoryPlacer behavior and cache-accounting hardening.
- A complete single-node deterministic JIT lifecycle:
  observe → fingerprint → hot path → synthesize → held-out validate → shadow → eligible → canary → active → monitor → demote/recompile.
- Restricted deterministic IR with no `eval`, `exec`, arbitrary imports, filesystem/network access, subprocesses, callbacks, or arbitrary generated Python.
- Immutable deterministic artifacts and durable route state across restart.
- Generation-bound canary/health evidence and fail-closed authority/freshness behavior.
- Internal red-team hardening, including executor/artifact mutation sealing.
- Direct OpenAI and Anthropic live validation with bounded, main-only secret-consuming workflows.
- Split format diagnostics and sanitized per-turn miss telemetry.
- Anthropic exact-value contract plus bounded deterministic canonical extraction while preserving raw compliance as a separate metric.

## Claim boundary

Supported:

> PCF v0.3 is a complete, tested single-node reference system for cache-aware context placement and bounded deterministic JIT execution, with live replicated validation on GPT-5.6 and Claude Sonnet 5.

Not claimed:

- distributed/multi-region production readiness;
- HA or consensus guarantees;
- independent third-party security certification;
- a passing real production pilot;
- production authority for learned classifier/specialist compile targets.

## Release-gate boundary

The repository's existing `v0.3.0rc1`/stable release gate remains unchanged. It requires a real four-arm production pilot, independent blind review, two distinct human approvals, protected `main`, exact version/tag matching, and sanitized bound evidence. This reference milestone does not fabricate or substitute that evidence.

## Milestone closure

Feature development for the v0.3 reference milestone is closed. Subsequent work belongs to a new milestone: distributed persistence/HA, production telemetry/orchestration, independent review, or additional compile targets.
